# Pac-Man

Arcade-accurate Pac-Man for the browser. Static site, no build step, no
runtime dependencies. Installable and fully playable offline.

## Running it

```
cd pacman && node tools/serve.mjs 8080
# open http://localhost:8080
```

ES modules need a real origin, so `file://` will not work.

## Controls

| Action | Keyboard | Touch | Gamepad |
| --- | --- | --- | --- |
| Move | Arrows / WASD | Swipe anywhere, or the D-pad | D-pad / left stick |
| Pause | P / Esc | Pause button | Start |
| Mute | M | Settings | — |
| Skip intermission | Enter / Space | — | A |

## Difficulty and mazes

**Easy** (the default) keeps every rule but loosens the numbers: eight lives,
refilled at every new level, plus one every 10,000; ghosts 25 % slower and
Pac-Man 5 % faster; later ghost-house release; eaten ghosts rest 7 s; fright of at least 6 s on every
level, longer scatter, no Cruise Elroy, and a dangerous ghost must actually
overlap Pac-Man. **Arcade** is the original machine, unchanged.

Levels are endless. Four mazes -- Classic, Orchid, Lagoon, Ember -- rotate every
three levels, each with its own colour theme. They share the arcade's middle
band (house, tunnels, fruit corridor), so ghost behaviour holds in all of them.

## How faithful is it

The engine follows the original hardware as documented in Jamey Pittman's
*Pac-Man Dossier*:

- per-level speed tables for Pac-Man, ghosts, frightened ghosts and tunnels
- the scatter/chase schedule, paused during fright, with forced reversals
- the four targeting personalities, including the overflow bug that shifts
  Pinky's and Inky's aim left when Pac-Man faces up
- red-zone tiles where ghosts may not turn upward
- ghost-house release by personal dot counters, the global counter after a
  death, and the idle timer
- Cruise Elroy, suspended after a death until Clyde leaves the house
- one-frame stall per dot, three per energizer, and cornering
- fright duration and flash count per level, fruit at 70 and 170 dots,
  extra life at 10,000, intermissions after levels 2, 5, 9, 13 and 17

The intro and intermission music are original compositions, and the
intermission cutscenes are original choreography.

## Layout

```
index.html            shell and every screen
manifest.webmanifest  PWA manifest
sw.js                 network-first service worker (offline fallback)
vercel.json           security headers, caching
src/
  maze.js       layout, tile classification                    (pure)
  engine.js     the simulation, one step per arcade frame      (pure)
  bot.js        autopilot for attract mode and soak tests      (pure)
  mazeshape.js  wall outlines traced from the tiles            (pure)
  sprites.js    vector art: Pac-Man, ghosts, fruit
  render.js     canvas renderer, effects, HUD, intermissions
  audio.js      synthesised sound, no samples
  input.js      keyboard, swipe, D-pad, gamepad
  save.js       settings and the top-five table
  main.js       loop, screens, layout, wiring
  ui.css
  fonts/        Outfit (SIL OFL 1.1, see OFL-Outfit.txt)
icons/          generated by tools/icons.mjs
tests/
  engine.test.mjs  rules, targeting, 30-level soak, determinism
  playtest.mjs     end-to-end in Chromium at five viewports
tools/
  serve.mjs   static server that mirrors the production headers
  shots.mjs   screenshots of every screen at five viewports
  icons.mjs   renders the icon set from the game's own sprites
  bundle.mjs  single self-contained HTML file (needs esbuild)
```

## Verifying

```
node --test tests/engine.test.mjs
node tests/playtest.mjs
```

Both need only Node 20+; the playtest also needs Playwright with Chromium.

## Wall rendering

The arcade draws walls as neon outlines inset into the wall tiles: single
lines around solid blocks, double lines along one-tile walls. `mazeshape.js`
reproduces that by eroding the union of wall tiles, tracing the result's
boundary into polygons, and rounding every corner. Convex corners get a radius
larger than concave ones by exactly the double-line spacing, so both lines of
every double wall stay concentric through each bend.
