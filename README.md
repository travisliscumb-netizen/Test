# Operation Blackgate

A GoldenEye 007 (N64)-style infiltration shooter that runs in a browser from a
single self-contained HTML file: no server, no install, no network. Touch-first
on phones, with keyboard and mouse on desktop.

**Play:** open `operation-blackgate.html`. That is the whole procedure.

- Three difficulty tiers that add objectives, as GoldenEye's did: Agent, Secret
  Agent (+ destroy the stockpile), 00 Agent (+ no lab staff casualties).
- Guards who run for alarm panels when they see you, path through the facility
  to find you, and drop their rifles when they fall.
- Head, body and limb hits with different effects; shoot an arm to disarm.
- Earned cheats (Paintball, DK Mode, Turbo, Infinite Ammo, Invincibility),
  per-tier best times and a GoldenEye-style debrief.

Full design and engineering notes: [`BLACKGATE.md`](BLACKGATE.md).

## Repository

| Path | What it is |
|---|---|
| `operation-blackgate.html` | The game, generated by `build.py`. Ship this. |
| `src/`, `vendor/`, `three.min.js` | Blackgate source (see `BLACKGATE.md`). |
| `tests/` | Blackgate browser test suite (Playwright). |
| `index.html`, `verify.js` | **Agent 64: Spy Ops**, the earlier game, kept playable. See [`AGENT64.md`](AGENT64.md), [`DECISIONS.md`](DECISIONS.md). |
| `deploy/` | Static publish root, generated by `build.py`: `/` is Blackgate, `/agent64/` is Agent 64. |
| `netlify.toml` | Publishes `deploy/` with no build command. |

## Build and test

```
python3 build.py      # regenerate operation-blackgate.html and deploy/
npm install           # Playwright, for the tests
npm test              # build --check + Blackgate browser suite + Agent 64 verifier
```

`npm test` fails if a generated file is stale, a test fails, a page logs an
error, or a page makes any network request.
