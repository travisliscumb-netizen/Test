# Crimson Realm

A one-on-one tournament fighter built for phones: original fighters, gore,
executions, and a ladder that gets a little harder every level. It installs
to the Home Screen with its own icon and plays fully offline.

Landscape only. It needs no build step and has no runtime dependencies.

---

## Running it

```
cd crimson-realm && python3 -m http.server 8080
# open http://localhost:8080 (on a phone: http://<your-computer-ip>:8080)
```

ES modules need a real origin, so `file://` will not work.

**Installing on a phone** (it must be served over HTTPS, e.g. any static host):
- **iPhone (Safari):** Share → *Add to Home Screen*.
- **Android (Chrome):** the title screen shows an *Install App* button, or use ⋮ → *Install app*.

## Controls

| Input | Touch | Keyboard | Gamepad |
|---|---|---|---|
| Move / jump / crouch | floating stick, left half | Arrows / WASD | D-pad / left stick |
| Punch | PUNCH | J | X / □ |
| Kick | KICK | K | A / ✕ |
| Block (hold) | BLOCK | L / Shift | B / ○, bumpers |
| Special | SPECIAL | I / Space | Y / △ |
| Pause | ‖ (bottom centre) | Esc / P | — |

Moves: P,P,P and P,P,K strings · K,K knockdown · ↓+P uppercut · ↓+K sweep (low) ·
air punch/kick · flip jumps · hold ↓+BLOCK against sweeps. When the loser is
dazed and **EXECUTE!** appears, press SPECIAL from anywhere.

## Difficulty

One dial, `d` in [0, 1], drives every AI trait: reaction delay, block rate,
anti-air, punishing, combo continuation, special use, mistakes, and damage on
both sides. See `difficultyFor()` in `src/config.js`.

- **Level 1** is near-unlosable: the CPU reacts about 0.7 s late, almost never blocks, and deals half damage.
- **Each level** after that adds a small step: about one frame of reaction and a few points of block rate and damage.
- **Level 10** is the boss. His size, reach and health are the step up, so his AI dial is offset down rather than spiked.
- **Past level 10** the ladder is endless and keeps climbing until level 34, then adds damage only.
- **Mercy:** each loss on the same level eases that level slightly, up to about 1.4 levels.

`tests/crimson-balance.mjs` proves this: a fixed-skill reference player wins 100% at
level 1, its win rate declines steadily with no cliff larger than 25 points
between neighbouring levels, and it wins at most 35% at level 16.

## Layout

```
crimson-realm/
  index.html            shell + every screen
  manifest.webmanifest  PWA: fullscreen, landscape, full icon set
  sw.js                 offline precache, cache-first with background refresh
  icons/                generated by tools/crimson-icons.mjs
  src/
    config.js       roster, move frame data, stages, ladder, difficulty curve  (pure)
    skeleton.js     pose library + forward kinematics                         (pure)
    engine.js       60 Hz deterministic fight sim: states, hits, rounds        (pure)
    ai.js           CPU opponent reading a delayed view of the player          (pure)
    fighter-art.js  lit, costumed fighter painter; hair/cloth physics
    stages.js       six parallax stages, perspective floors, weather
    render.js       compositing, particles, gore, HUD, adaptive resolution
    audio.js        synthesised SFX, generative score, announcer voice
    input.js        floating stick + multi-touch buttons, keyboard, gamepad
    save.js / main.js / icon.js / ui.css
```

Graphics are drawn at the screen's native resolution (up to 1080p backing),
with stage-tinted key and rim lighting on every limb, floor reflections,
additive glows, motion afterimages, and 60 fps simulation. If a device can't
hold 60 fps, resolution steps down automatically and the choice is remembered.
